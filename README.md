<h2 align= "center"> Overview </h2 align = "center">
<p align="center">AegisMR is a Mixed Reality cybersecurity and networking education platform developed as a Final Year Software Engineering project for the Meta Quest 3S.</p>

<p align="center">The platform combines a Unity-based Mixed Reality frontend with a Python-powered network simulation backend to visualise network traffic, simulate attack scenarios, and demonstrate defensive security concepts in real time.</p>

<p align="center">A key research objective of the project is to investigate the effectiveness of Mixed Reality as a pedagogical tool for cybersecurity education. Through experimentation and evaluation, AegisMR will compare a traditional 2D learning environment with an immersive 3D Mixed Reality learning environment to assess whether spatial visualisation and interactive learning can improve learner understanding, engagement, and knowledge retention of foundational networking and cybersecurity concepts.</p>
