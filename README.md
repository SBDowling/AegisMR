<h1 align="center">🛡️ AegisMR</h1>

<p align="center">
  <strong>Mixed Reality Cybersecurity & Networking Education Platform</strong>
</p>

<p align="center">
  Final Year Software Engineering Project
</p>

<p align="center">
  Meta Quest 3S • Unity • C# • Python • OpenXR • WebSockets • Scapy
</p>

<h2 align= "center"> Overview </h2>
<p align="center">AegisMR is a Mixed Reality cybersecurity and networking education platform developed as a Final Year Software Engineering project for the Meta Quest 3S.</p>

<p align="center">The platform combines a Unity-based Mixed Reality frontend with a Python-powered network simulation backend to visualise network traffic, simulate attack scenarios, and demonstrate defensive security concepts in real time.</p>

<p align="center">A key research objective of the project is to investigate the effectiveness of Mixed Reality as a pedagogical tool for cybersecurity and networking education. Through experimentation and evaluation, AegisMR will explore how immersive visualisation, interactivity, and experiential learning influence learner understanding, engagement, and knowledge retention of foundational networking and cybersecurity concepts.</p>

<h2 align="center">🥽 Hardware & Platform Capabilities</h2>

<p align="center">
AegisMR is being developed for the Meta Quest 3S Mixed Reality headset. The platform leverages the device's Mixed Reality, spatial computing, and hand-tracking capabilities to create immersive educational experiences designed to support the teaching of foundational networking and cybersecurity concepts.
</p>

<ul>
  <li><strong>Mixed Reality Passthrough</strong> - Integrates virtual network topologies, devices, and packet visualisations within the user's physical environment.</li>

  <li><strong>Hand Tracking</strong> - Enables intuitive controller-free interaction with network devices, packets, and educational content.</li>

  <li><strong>Spatial Computing</strong> - Positions network infrastructures and cybersecurity visualisations within a three-dimensional space that can be explored by the learner.</li>

  <li><strong>Room-Scale Interaction</strong> - Allows users to physically move around and investigate network topologies, packet flows, and attack scenarios from different perspectives.</li>

  <li><strong>Standalone Deployment</strong> - Operates directly on the Meta Quest 3S without requiring a dedicated desktop environment during deployment.</li>
</ul>

<h2 align="center">🏗️ Technology Stack</h2>

<p align="center">
AegisMR combines Mixed Reality technologies, real-time network simulation tools, and modern software engineering practices to deliver an immersive cybersecurity and networking education platform.
</p>

<h3>Frontend Technologies</h3>

<ul>
  <li><strong>Unity</strong> - Primary development environment used to create the Mixed Reality application, interactive educational experiences, and 3D visualisations.</li>

  <li><strong>C#</strong> - Used to develop application logic, interaction systems, networking visualisations, packet behaviours, and user interface functionality.</li>

  <li><strong>OpenXR</strong> - Provides access to Meta Quest 3S Mixed Reality capabilities and enables integration with spatial computing features.</li>
</ul>

<h3>Backend Technologies</h3>

<ul>
  <li><strong>Python</strong> - Serves as the network simulation engine responsible for packet generation, cybersecurity scenarios, data processing, and educational content delivery.</li>

  <li><strong>Scapy</strong> - Used for packet creation, packet manipulation, traffic generation, and cybersecurity-focused network simulations.</li>

  <li><strong>WebSockets</strong> - Provides real-time communication between the Python backend and Unity frontend, enabling live visualisation of simulated network activity.</li>
</ul>

<h3>Development & Testing Tools</h3>

<ul>
  <li><strong>Visual Studio Code</strong> - Primary development environment for Python, C#, documentation, testing, and version control workflows.</li>

  <li><strong>Blender</strong> - Used for the creation and modification of 3D models and assets representing network devices and infrastructure.</li>

  <li><strong>Git & GitHub</strong> - Source control, project management, documentation, and version tracking.</li>

  <li><strong>PyTest</strong> - Automated testing framework used to validate Python backend functionality.</li>

  <li><strong>Unity Test Framework</strong> - Automated testing framework used to validate Unity components and application behaviour.</li>
</ul>

<h2 align="center">🚀 Core Features</h2>

<p align="center">
AegisMR transforms traditionally abstract networking and cybersecurity concepts into immersive, interactive Mixed Reality learning experiences designed to improve engagement, comprehension, and knowledge retention.
</p>

<ul>
  <li><strong>Interactive Network Topology Visualisation</strong> - Explore routers, switches, servers, and end devices within an immersive three-dimensional environment.</li>

  <li><strong>Real-Time Packet Flow Visualisation</strong> - Observe packets travelling through networks and monitor how communication occurs between devices.</li>

  <li><strong>Packet Inspection</strong> - Examine packet information and network traffic to better understand communication processes.</li>

  <li><strong>TCP/IP Communication Demonstrations</strong> - Visualise fundamental networking concepts and communication protocols.</li>

  <li><strong>TCP Three-Way Handshake Simulation</strong> - Observe the process of connection establishment between clients and servers.</li>

  <li><strong>SYN Flood Attack Simulation</strong> - Demonstrate the impact of denial-of-service style attacks on network resources.</li>

  <li><strong>ARP Spoofing Simulation</strong> - Illustrate how attackers can manipulate network communications.</li>

  <li><strong>Firewall Visualisation</strong> - Demonstrate packet filtering concepts and show how firewalls regulate network traffic.</li>

  <li><strong>Defensive Security Mechanisms</strong> - Visualise how security controls can mitigate common cyber threats.</li>

  <li><strong>Mixed Reality Interaction</strong> - Navigate and interact with educational content using hand-tracked gestures.</li>

  <li><strong>Educational Learning Modules</strong> - Structured experiences designed to teach foundational networking and cybersecurity concepts.</li>

  <li><strong>Assessment & Evaluation</strong> - Supports the collection of feedback and learning outcomes for educational evaluation purposes.</li>
</ul>
